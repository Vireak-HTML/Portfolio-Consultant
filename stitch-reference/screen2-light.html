02 // Core Doctrine

Craft & Engineering Philosophy

bolt
01. Principle

Performance First

Zero jank is a baseline requirement, not an optimization sprint. I measure interaction to next paint (INP) obsessively, eliminate superfluous re-renders, and favor CSS containment with GPU-accelerated compositing.

Target: Sub-50ms INP

02. Principle

Accessibility by Default

Inclusion is architectural integrity. Strict ARIA semantics, semantic document landmarks, deliberate roving tab indexes, and high-contrast color calculations are woven into the foundation before the first visual mock.
